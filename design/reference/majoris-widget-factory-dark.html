System Design Notes

Rules reflected throughout the gallery.

Cool dark neutrals: #18181B → #202023 → #28282C establish depth without blue-black tinting.
Focus: #818CF8 improves visibility on dark surfaces while retaining the Majoris indigo family.
Controls: the same stationary 128ms state fades remain; only colour, border and shadow values change.
Window controls: the exact 16×16 glyphs remain monochrome; close alone gains destructive red on interaction.
Elevation: deeper black shadows pair with subtle light borders to keep dark surfaces distinct.

Native document tab contract

40px strip; 14px Medium / SemiBold; 24px close controls.
