Native implementation boundary

Baseline · retain

Light/dark semantic tokens, 4px/8px radii, headerbar geometry, window control SVGs, buttons, entry, lists, dialogs, scrollbars, cards, Notebook tabs.

Theme changes · propose

Opt-in Adw.TabBar treatment, majoris-editor-toolbar, majoris-statusbar, Majoris GtkSourceView light/dark schemes.

Application changes · later

Apply semantic CSS classes, choose GtkSourceView schemes, supply tab labels/dirty indicators, preserve native behaviour and accessibility.
