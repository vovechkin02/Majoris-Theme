Majoris Full Theme Mockup — Light + Dark

This consolidated mockup is based on the latest Majoris Theme package, the existing widget-factory references, and the proposed menu refinements. It shows both light and dark in one document, includes the existing login/greeter elements, and applies the proposed 4px menu outer padding plus the intended kbd-style accelerator treatment and 2px separator vertical margins with safer line-height and no clipped shortcut text.
